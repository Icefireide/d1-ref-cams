# Referee Camera Check

A one-page tool for checking every player's camera before a match.

1. Open the page.
2. On the **Set up** tab, fill in the match and the teams: each player's IGN and their VDO.Ninja view link (or just the camera id). To save typing, open "Start from the roster CSV", load the roster sheet, pick the game and up to four schools, and press "Use these schools".
3. Switch to the **Cameras** tab to see every selected player's live camera and whether it has connected.
4. Press **Copy link** and send it to the referees. The link holds the whole match, so they open it and land straight on the Cameras tab.

Development: `npm test` runs the tests (node only, no dependencies).
